EL SIMBOLO, EN UNA LINEA
---------------------------------------------------------------------
Cuatro piezas: tres puestas y una todavia por poner. Es lo que vende la
empresa —sistemas armados por modulos— y la pieza vacia deja la frase
servida: «y si te falta una, se agrega».


LOS COLORES
---------------------------------------------------------------------
  Verde profundo   #14503F   El principal: simbolo y nombre.
  Salvia           #4E8C74   El acento: el «bo» de Bolivia.
  Salvia clara     #7FC3A4   El mismo acento, para fondo oscuro.
  Gris             #7B8794   La bajada.
  Negro puro       #000000   SOLO para la version de una tinta.

Se eligio verde por dos razones, y ninguna es de gusto:

  * La primera version usaba el azul #1D4ED8, que es el que trae
    Tailwind por defecto —el mismo de medio internet— y se habia
    elegido para que la marca combinara con la pantalla del Sistema de
    Ventas. Eso estaba mal de raiz: la empresa va a vender varios
    sistemas y no puede vestirse del color de uno solo.
  * En software casi nadie usa verde. Entre diez folletos sobre un
    mostrador, este se distingue.

El acento salvia sobre blanco da 3,9:1 de contraste. Para texto de
lectura seria poco; para un logo, a los tamaños en que se usa, se lee
bien. No lo uses para parrafos.

SEIS COSAS QUE NO HAY QUE HACER
---------------------------------------------------------------------
1. No lo estires. Si cambias el ancho, cambia el alto en la misma
   proporcion. Un logo aplastado se nota y queda mal.

2. No le cambies el color. Hay una version para cada fondo; si ninguna
   sirve, usa la de una tinta.

3. No uses la punteada en chico. Por debajo de 150 px de ancho va la
   compacta. Mira la ultima fila de hoja-de-marca.svg y se entiende
   sin explicacion.

4. No lo pongas sobre un fondo con el que no contrasta. Sobre verde,
   sobre una foto cargada o sobre un fondo medio: usa el negativo o
   ponle una caja blanca detras.

5. No uses la teja normal de foto de perfil. WhatsApp, Facebook e
   Instagram recortan un CIRCULO inscrito en el cuadrado, y las esquinas
   del simbolo quedan justo afuera: sobresalen 1,1 unidades y se las come
   el recorte. Para eso esta innovasoftbo-whatsapp-perfil.png, que lleva
   mas margen.

6. No rehagas el texto escribiendolo. El nombre esta convertido a
   curvas: es un dibujo, no texto. Si alguien lo reescribe con la
   tipografia de su computadora, va a salir distinto y no va a coincidir
   con nada de lo ya impreso.


LA TIPOGRAFIA
---------------------------------------------------------------------
DejaVu Sans, que ya venia en el proyecto con dompdf. Se eligio por su
licencia: Bitstream Vera, con los cambios de DejaVu en dominio publico.
Permite usarla, modificarla y vender lo que se haga con ella.

Las de Windows —Segoe UI, Calibri— NO sirven para esto: su licencia las
ata a productos de Microsoft, y hacer con ellas el logo de una empresa
es un problema legal que no se ve hasta que alguien lo mira.

Si mas adelante quieres un nombre con mas caracter, Montserrat o
Poppins (Google Fonts, licencia OFL, permiten logos) son buenas
candidatas. Se baja la tipografia y se regenera todo el juego.


COMO SE REGENERA
---------------------------------------------------------------------
Todo esto sale de scripts, no de un programa de diseño:

    pip install fonttools pillow
    cd docs/marca
    python logo.py          # los SVG
    python logo_png.py      # los PNG
    python hoja_marca.py    # la hoja de revision

Para cambiar un color se toca UNA linea en logo.py y se regenera el
juego completo. Asi no puede pasar que la tarjeta tenga un verde y el
folleto otro.
